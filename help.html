开始使用

  1. 使用 Windows 上的最新版 Chrome 或 Edge，打开正式 HTTPS 网址。
  2. 点击“开启摄像头”，允许相机访问。也可以选择本地视频，视频不会上传。
  3. 首次需要下载约110 MB模型和运行文件，加载时间取决于网络。优先尝试GPU；不兼容时可改为CPU兼容模式。
  4. 让完整身体及球拍进入画面，保持光线充足。青色为身体骨架，橙色为球拍轴线。不显示人脸关键点。
  5. 点击“停止识别”释放摄像头。镜像仅改变显示方向。

如何理解结果

本页使用YOLO26人体姿态、YOLO11球拍检测及RacketVision RTMPose球拍关键点模型。默认关联画面中主要人物及其手附近的球拍。多人交叉或遮挡可能切换目标。

球拍端点置信度不足或明显越界时暂时隐藏轴线。端点是模型预测，并非人工精标。网页没有生成虚拟球拍延长线，也不提供真实三维拍面角、拍头加速度或技术评分。

“分析帧率”表示每秒完成标注的画面数；“单帧处理”是浏览器模型处理耗时。低帧率时丢弃旧帧，保证不累计排队；所有标注与送入模型的同一帧对齐。首次运行、设备温度、后台程序和模型初始化都会影响速度。

隐私与费用

所有视频处理均在浏览器本地进行；页面不向服务器发送摄像头或视频内容，不自动录制，不收集账号。模型与运行文件需要首次下载。采用免费静态托管时，无需云端推理服务器，仍需遵守托管平台的免费额度和使用条款。

识别不到怎么办

确认持拍手和完整球拍可见，减少背光、运动模糊和复杂背景。CPU模式可能较慢；可先用光线清楚的慢速视频测试。若相机被其他程序占用，请先关闭占用程序。

本地直接双击index.html无法运行；需要本地HTTP服务或正式HTTPS网址。公共HTTP地址不能申请摄像头。
